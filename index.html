system design lab

Learn system design by breaking things on purpose.

Every page is a small simulation of Encore, a fictional concert ticket app, as it grows from one server into a production system. You push traffic, cause the failure, apply the fix, and see why it works.

Meet the teamAna builds the backend, Ben handles payments, Cai builds the frontend, and Dee keeps it all running. Each page drops them into a new problem.
