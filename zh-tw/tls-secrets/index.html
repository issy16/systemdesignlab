試試看

  
    
  
    
    
    TLS（傳輸中加密）
    加密兩台機器之間的資料，並用一張由瀏覽器信任的機構簽署的憑證（certificate），證明伺服器真的是它所宣稱的那一個。凡是資料傳輸的地方都要用：瀏覽器到網站，以及服務到服務。
    
    
    機密管理（Secrets management）
    金鑰、密碼和權杖放在機密儲存庫裡（或在部署時注入成環境變數），絕不放在程式碼或 git 裡。每個機密都要能輪替（rotate）：換成新的，同時撤銷舊的。
    
  
    
  
    關鍵差別
    加密只有在金鑰保密時才有用。TLS 讓攻擊者讀不到傳輸中的資料；外洩的金鑰則讓他們直接從大門走進來。機密一旦曝光，刪掉它也無法讓它恢復保密。你必須輪替它。

    私密＋真實
    TLS
    加密連線並驗證伺服器的憑證。攻擊者看得到你連到哪裡，看不到你送了什麼。
    
    
    到處都要
    傳輸中加密
    不只是瀏覽器：資料庫、佇列和內部 API 也一樣。資料中心內部的網路並不會自動變得安全。
    
    
    移出程式碼
    機密管理（Secrets management）
    把機密存在機密管理工具裡，每個服務只給它需要的，一有外洩就輪替。
    
  
    
  
    取捨
    TLS 只要一點設定，在今天幾乎不影響速度，沒有理由跳過它。機密管理工具會多一個相依服務和一些流程，但一把外洩的金鑰造成的損失可能大得多。把憑證更新和機密輪替自動化，別讓它們依賴某人記得去做。
