    關鍵差別

    沒有斷路器時，每個請求都會持續呼叫一個明知壞掉的相依服務，而且每次都等滿逾時。斷路器會計算失敗次數；連續失敗幾次後它就開啟：呼叫立刻被跳過，改用備援方案（fallback）。冷卻一段時間後，它會放一次測試呼叫通過，成功的話就再度關閉。

    負載平衡器把流量送到 Encore API 的三份副本。api-2 剛啟動，還在載入快取。api-3 卡在死結裡：行程還在跑，卻永遠不回應。選擇平台要執行哪些檢查，然後讓時間往前走。

    存活探針（Liveness probe）

    「這個行程卡住了嗎？」連續失敗幾次就重新啟動它。這能修好死結和卡死。

    就緒探針（Readiness probe）

    「它現在能接流量嗎？」不能的話就停止送請求給它，但不要重新啟動。用於啟動中、暖機中，或資料庫連線中斷時。

    停止呼叫
    斷路器（circuit breaker）
    連續失敗後，跳過呼叫並改用備援方案。偶爾測試一下，恢復正常時再繼續呼叫。
    
    
    重新啟動
    存活探針
    偵測卡住的行程並重新啟動它。保持簡單：不要因為相依服務掛了就讓它失敗。
    
    
    繞道而行
    就緒探針
    偵測還不能服務的執行個體，把它從負載平衡器中移除，直到它準備好。
    
  
    
  
    取捨
    斷路器把緩慢的失敗變成快速的、局部的失敗：歌迷看到的是沒有推薦內容的頁面。前提是你設計了備援方案。門檻太敏感，小小波動就會開啟；太寬鬆，等它開啟時傷害已經造成了。
