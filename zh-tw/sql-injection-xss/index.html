    關鍵差別
    兩種攻擊的原理相同：使用者的文字被混進程式碼（SQL 或 HTML），電腦分不出你的文字在哪裡結束、程式碼從哪裡開始。修法的原理也相同：讓資料和程式碼分開。SQL 用參數，HTML 用輸出跳脫（escape）。

    攻擊資料庫
    SQL 注入
    被拼進查詢字串的輸入會改變查詢本身：跳過密碼檢查、讀取別人的資料、刪除資料表。修法：參數化查詢。
    
    
    攻擊你的使用者
    XSS
    以 HTML 插入頁面的輸入會變成腳本，在每位訪客的瀏覽器裡以他們的身分執行。修法：插入文字而不是 HTML（輸出跳脫），再加上 CSP。
    
    
    原則
    資料 ≠ 程式碼
    永遠不要把使用者的文字拼進程式碼。交給資料庫驅動程式或瀏覽器把兩者分開。
    
  
    
  
    取捨
    這些修法幾乎沒有成本，現代框架也預設就會做。風險藏在那些逃生口：原生 SQL 輔助函式、innerHTML、dangerouslySetInnerHTML、|safe。每一個都要審查。
