    TLS（传输中加密）
    加密两台机器之间的数据，并用一张由浏览器信任的机构签署的凭证（certificate），证明服务器真的是它所宣称的那一个。凡是数据传输的地方都要用：浏览器到网站，以及服务到服务。
    
    
    机密管理（Secrets management）
    密钥、密码和权杖放在机密保存库里（或在部署时注入成环境变量），绝不放在代码或 git 里。每个机密都要能轮替（rotate）：换成新的，同时撤销旧的。
    
  
    
  
    关键差别
    加密只有在密钥保密时才有用。TLS 让攻击者读不到传输中的数据；外泄的密钥则让他们直接从大门走进来。机密一旦曝光，删掉它也无法让它恢复保密。你必须轮替它。

    私密＋真实
    TLS
    加密连接并验证服务器的凭证。攻击者看得到你连到哪里，看不到你送了什么。
    
    
    到处都要
    传输中加密
    不只是浏览器：数据库、队列和内部 API 也一样。数据中心内部的网络并不会自动变得安全。
    
    
    移出代码
    机密管理（Secrets management）
    把机密存在机密管理工具里，每个服务只给它需要的，一有外泄就轮替。
    
  
    
  
    取舍
    TLS 只要一点设置，在今天几乎不影响速度，没有理由跳过它。机密管理工具会多一个相依服务和一些流程，但一把外泄的密钥造成的损失可能大得多。把凭证更新和机密轮替自动化，别让它们依赖某人记得去做。
