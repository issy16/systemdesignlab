    关键差别
    两种攻击的原理相同：用户的文字被混进代码（SQL 或 HTML），电脑分不出你的文字在哪里结束、代码从哪里开始。修法的原理也相同：让数据和代码分开。SQL 用参数，HTML 用输出跳脱（escape）。

    攻击数据库
    SQL 注入
    被拼进查找字符串的输入会改变查找本身：跳过密码检查、读取别人的数据、删除数据表。修法：参数化查找。
    
    
    攻击你的用户
    XSS
    以 HTML 插入页面的输入会变成脚本，在每位访客的浏览器里以他们的身分运行。修法：插入文字而不是 HTML（输出跳脱），再加上 CSP。
    
    
    原则
    数据 ≠ 代码
    永远不要把用户的文字拼进代码。交给数据库驱动程序或浏览器把两者分开。
    
  
    
  
    取舍
    这些修法几乎没有成本，现代框架也默认就会做。风险藏在那些逃生口：原生 SQL 辅助函数、innerHTML、dangerouslySetInnerHTML、|safe。每一个都要审查。
